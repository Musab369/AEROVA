# AEROVA – Urban Air Quality Assistant

**Understand your air. Protect your health.**

A premium dark-mode air quality dashboard built with **only HTML5, CSS3 and vanilla JavaScript**. No frameworks, no build step, no backend, no APIs, no AI model.

> ⚠️ **All readings, alerts, recommendations, the planner and chat replies are SAMPLE / DEMONSTRATION data.** Nothing here is live data or medical advice. Every data card is labelled accordingly.

## Run it

Open `index.html` in any modern browser. Or serve the folder:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Features

- Sidebar navigation that becomes a slide-in mobile menu (scrim, Esc to close, focus handling)
- Smooth scrolling with scroll-spy: active nav state and page title follow the section in view
- Hero with location card; location panel with city search (OpenWeather Geocoding), a click-to-use "my current location" button (browser geolocation, only on click) and suggested cities; the last chosen city is remembered; notification panel (mark as read, badge count)
- AQI overview: animated gauge, count-up score (164 / 500, Unhealthy, PM2.5), colour-coded scale with marker
- Weather card (temperature, humidity, wind, visibility, conditions)
- Six pollutant cards (PM2.5, PM10, CO, NO₂, SO₂, O₃) with Good / Moderate / High indicators and animated bars
- 24-hour AQI bar chart in pure DOM/CSS: 24h / 12h / 6h range, hover, tap and keyboard tooltips
- Recommendation cards with icon, priority label and hover animation
- Timeline-based daily planner (morning, commute, midday, evening exercise, night)
- Chat assistant with suggested questions, Enter-to-send, typing indicator and scripted replies
- Respects `prefers-reduced-motion`, keyboard accessible, touch-friendly targets, no horizontal overflow

## Where to plug in the real thing later

| Area | Change |
| --- | --- |
| Air quality & weather | Replace the sample constants at the top of `js/script.js` (`AQI`, `POLLUTANTS`, `HOURLY_AQI`) with API data, then call the render functions |
| Recommendations | Replace `RECOMMENDATIONS` and `PLANNER` with output from a recommendation engine |
| Chat | Replace the `reply()` function in `initChat()` with a call to your AI service |
| Locations | Use the `data-city` attributes on the location list as a starting point for a geocoding lookup |

## Notes

- The location selector only changes the displayed place; the sample readings stay the same for every city, and a toast says so.
- Chat replies are chosen by simple keyword matching and are not generated by any model.
- Uses system fonts (Inter if installed) so there are no external dependencies.
